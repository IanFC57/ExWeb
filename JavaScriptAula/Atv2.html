Como declarar Variáveis?

Usamos Let ou Var para declara variáveis

var nome; // cria uma variável global com identificador nome
let idade; // cria uma variável local com identificador idade

Funções em javascript

// Exemplo

return a + b;
}

Tratamento de eventos em javascript

Tratamos eventos em js usando addEventListener que vincula uma função a um evento especifico do DOM

Exemplo:

document.addEventListener('click', function(){
console.log("Clique detectado")
})
