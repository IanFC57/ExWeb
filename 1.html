Questão 1

O que é HTML?

HTML não é uma linguagem de programação, mas sim uma linguagem de marcação. Ele serve para criar a estrutura das páginas na internet.

Qual o papel dele na Web?

Ele funciona como o "esqueleto" do site. É ele que diz para o navegador onde fica um título, um parágrafo, uma imagem ou um link, organizando o conteúdo para o usuário ler.

O que eu usei nesta página:

  • Tags para estruturar (header, main, footer)
  • Tags de texto (h1, h2, p)
  • Tags de lista (ul, li)
