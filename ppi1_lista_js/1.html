O que é JavaScript?

1. Motivação para a criação do JavaScript

Javascript surgiu em 1995 e foi criada por Brendan Eich, a pedido da empresa Netscape (um dos primeiros navegadores) com o objetivo de validar formulários HTML, para criar interações mais dinâmicas ao desenvolver páginas da Web, aplicativos, servidores, jogos, etc.

2. Diferença entre execução no Navegador e no Servidor

Client: Aplicações Client Side são renderizadas e processadas no lado do cliente, ou seja, no navegador dos usuários. Sendo assim, todo gerenciamento de rotas, requisições, interações, etc... Serão feitas via JavaScript onde o navegador vai interpretá-las e executá-las.
Server: Aplicações Server Side são renderizadas e processas pelo servidor, o navegador apenas vai receber os códigos HTML e colocar na tela, as informações já vem montadas pela resposta do servidor não precisamos disparar uma requisição para pegar os dados e depois montar uma tabela, a mesma já vem montada.

3. O conceito de Sandbox no navegador

Um ambiente sandbox é uma máquina virtual isolada na qual um código de software potencialmente inseguro pode ser executado sem afetar os recursos de rede ou os aplicativos locais. Pense em um sandbox como um ambiente controlado onde aplicativos, códigos e arquivos podem ser testados ou executados para verificar seu comportamento. Se o software se comportar de forma maliciosa ou inesperada, ele não terá o poder de afetar nada fora desse ambiente isolado.

4. Objetos globais

O objeto global fornece variáveis ​​e funções que estão disponíveis em qualquer lugar. Por padrão, inclui aquelas que são inerentes à linguagem ou ao ambiente.
