Como funciona o protocolo HTTP?

O HTTP (Protocolo de Transferência de Hipertexto) é a base da comunicação na Web. Ele funciona no modelo Cliente-Servidor.

O Cliente (seu navegador) faz uma Requisição (Request), e o Servidor (onde o site está hospedado) processa e devolve uma Resposta (Response).



1. A Requisição (Request)

É o pedido que o cliente faz. Exemplo de um cliente enviando um formulário de cadastro:

POST /cadastrar HTTP/1.1
Host: www.meusite.com.br
User-Agent: Chrome/120.0
Content-Type: application/json

{"nome": "Maria", "idade": 25}

Campos principais:

  • Linha Inicial: Mostra o Método (POST - para enviar dados), o Caminho (/cadastrar) e a versão (HTTP/1.1).
  • Cabeçalhos (Headers): Informações extras, como o site destino (Host) e o tipo de conteúdo sendo enviado (JSON).
  • Corpo (Body): Os dados de verdade (o nome e a idade da Maria).

2. A Resposta (Response)

É o que o servidor devolve após processar o pedido. Exemplo de sucesso no cadastro:

HTTP/1.1 201 Created
Date: Sex, 20 Mar 2026 15:00:00 GMT
Server: Apache
Content-Type: application/json

{"mensagem": "Cadastro realizado com sucesso!"}

Campos principais:

  1. Linha de Status: Mostra a versão (HTTP/1.1), o Código de Status (201 - que significa "Criado") e a mensagem de status (Created).
  2. Cabeçalhos (Headers): Detalhes do servidor, como data, hora e formato da resposta.
  3. Corpo (Body): A mensagem final que o servidor entrega ao cliente confirmando que deu tudo certo.
